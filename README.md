# E-commerce Sales Analysis Using Python

## Project Overview
This project analyzes sample e-commerce sales data using Python to understand sales performance, product trends, and category-wise revenue.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- GitHub

## Dataset
The dataset contains 10 sample orders with order dates, products, categories, quantities, unit prices, and customer cities.

## Analysis Performed
- Data inspection and quality checks
- Missing value and duplicate checks
- Order-level sales calculation
- Product-wise sales analysis
- Category-wise sales analysis
- Monthly sales trend visualization
- Business insights

## Key Findings
The project calculates total sales, identifies products and categories with the highest sales, and compares sales across months.

## How to Run
1. Install the required libraries using `pip install -r requirements.txt`.
2. Open `ecommerce_sales_analysis.ipynb` in VS Code with the Python and Jupyter extensions installed.
3. Run the notebook cells in order.

## Project Status
Completed as a beginner Python data analysis project.

## Note
This project uses a small sample dataset created for learning and demonstration purposes. Its findings should not be treated as real business results.
